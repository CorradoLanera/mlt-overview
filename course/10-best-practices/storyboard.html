  • Poll 22 — "You finish training, look at the test set, see accuracy =92%= 92\%. You bump the regularisation and check the test again: 93%93\%. Is the second number a faithful test number?" (opzioni yes / no, because we changed the model after seeing a test number / no, but only if we report the first number too / only after a fresh validation) — diagnostico sulla leakage rule (R22). Distrattori: yes = non ha applicato R22; yes if we report both = ha confuso trasparenza con correttezza; only after a fresh validation = ha la soluzione ma non la regola (è la risposta dello studente che ha lavorato in lab; premiala come operativamente corretta ma sottolinea che la regola sotto è "il test è già stato contaminato quando hai modificato il modello dopo averlo visto").
