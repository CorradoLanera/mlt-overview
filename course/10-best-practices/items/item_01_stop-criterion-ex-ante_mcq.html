Item 01 — Earn complexity: when the stop-criterion is written

ID: IB-10-best-practices-01 Learning objective: Plan a first iteration of an ML project as the simplest model on the smallest sensible feature set, and write an explicit stop-criterion before adding complexity. Concretely, given a problem and a dataset, state (a) the baseline model (e.g. logistic regression on 55–1010 features), (b) the baseline metric and the target value that would make the simple model "good enough", and (c) the single failure mode that would justify increasing model complexity — and not before. The rationale: more parameters and richer features are paid for in robustness, interpretability, and risk of overfitting — so each added unit of complexity must be earned by a failure of the simpler model (Obj. 1).

Category: Comprehension Type: MCQ Difficulty: medium Chapter: 10-best-practices

Question

A junior colleague on your team — Marco — is about to start an audit on 3030-day ICU readmission. The dataset has 50005\,000 patients with 5050 candidate features and a positive-class prevalence p≈5%p \approx 5\%; he must defend the model to the clinical lead and the ethics committee three weeks from today. He shows you four versions of the Methods section of his planning document — four different ways of writing the stop-criterion that the chapter's earn complexity discipline asks for.

Which of the four versions applies the discipline correctly?

Options

  • A) Marco trains a logistic regression on a clinically-chosen 66-feature subset and reads the validation result (AUPRC 0.270.27). He then trains a gradient boosting model on the same features and reads its validation result (AUPRC 0.310.31). Once both results are in front of him, he writes the following sentence in the Methods section: "We adopted gradient boosting because logistic regression failed to reach the AUPRC target we had set for the baseline."
  • B) Marco writes, at the top of his planning document — before any training — the following: "We will train gradient boosting on 3030 candidate features as our primary model, because gradient boosting consistently outperforms logistic regression on tabular clinical data. We will report AUPRC and recall on a held-out test set. If the result is unsatisfactory, we will revisit the modelling choice."
  • C) Marco writes, at the top of his planning document — before any training — the following: "Baseline: logistic regression on six clinically-chosen features (age, ICU length of stay, Charlson comorbidity index, prior 9090-day admissions, discharge-time eGFR, number of medications at discharge). Baseline metric and target: AUPRC ≥0.30\ge 0.30 on the validation split. Escalation rule: if the baseline does not reach AUPRC 0.300.30 on validation, we escalate to gradient boosting on a wider clinical feature set; if the baseline reaches the target, we ship the baseline."
  • D) Marco writes, at the top of his planning document — before any training — the following: "Baseline: logistic regression on six clinically-chosen features. Baseline metric and target: AUPRC ≥0.80\ge 0.80 on the validation split. Escalation rule: if the baseline does not reach AUPRC 0.800.80, we escalate to gradient boosting."

Expected answer

Correct: C. Option C is the only one that carries all three components of the chapter's earn complexity discipline, each correctly placed in time:

  • Timing — ex ante. The stop-criterion is written before any training has begun. The discipline is temporal: writing it before commits Marco to a rule he must then follow; writing it after lets the rule be shaped by results he has already seen, which is rationalisation, not discipline.
  • Baseline — simplest model on smallest sensible feature set. Logistic regression on 66 clinically-motivated features is the simplest model a clinical lead would recognise and interrogate. Obj. 1 explicitly: the simplest model on the smallest sensible feature set.
  • Target — realistic given the prevalence. AUPRC ≥0.30\ge 0.30 at p=5%p = 5\% is a target the simple model could plausibly reach, so the criterion is a real test of the baseline, not a rigged one. Escalation then becomes a documented failure of the simpler model — which is exactly what "each added unit of complexity must be earned by a failure of the simpler model" requires.
  • Escalation rule — single, named, if-then. One trigger (the baseline misses AUPRC 0.300.30 on validation), one direction (gradient boosting on a wider clinical feature set), and an explicit not-escalate branch ("if the baseline reaches the target, we ship the baseline"). The criterion has a real chance of stopping at the baseline, which is the defining property of a binding stop-criterion.

Why the distractors are plausible but wrong:

  • A is wrong on timing. Marco writes the stop-criterion after he has seen both the baseline result and the escalation result. He is now describing a sequence of decisions he has already made, in the language of "we set a target, the baseline failed, we escalated" — a defensible-sounding sentence on a slide that did not, in fact, govern the work. The chapter's discipline is precisely the move that A skips: writing the rule before the run, so the rule can constrain the run. A student who picks A has read "a stop-criterion was specified in the methods section" (yes) as equivalent to "a stop-criterion was specified before training" (no — the Methods section was written last). This is also the most common form of the failure in published clinical-ML papers: the Methods section is written after the experiments and reads as if the methodology had been pre-registered. It had not. The chapter's earn complexity discipline names this failure and asks the student to refuse it.
  • B is wrong on the baseline. Marco starts the work with gradient boosting on 3030 features as his primary model — not as an escalation from a documented failure of a simpler baseline. There is no simple model in the planning document, and so there is no documented failure of the simpler model to earn the complexity. The sentence "gradient boosting consistently outperforms logistic regression" is a defence of the choice in general, not a defence of the choice on this dataset given a documented baseline result. The ethics committee's question "why this model?" cannot be answered with population-level prior beliefs about model families; it must be answered with a project-level documented failure. A student who picks B has read "empirically better in general" as a sufficient clinical-defence substitute for "earned on this project by the failure of the simpler alternative" — exactly the substitution Obj. 1 rules out. The closing clause "if the result is unsatisfactory, we will revisit the modelling choice" compounds the failure: it is a vague stop-criterion (no metric, no threshold, no direction) embedded in a primary-model choice that already skips the baseline.
  • D is the subtlest distractor, because the timing is right (the document is written before any training) and the structure is right (baseline + target + escalation rule) — but the target is rigged. AUPRC ≥0.80\ge 0.80 on a problem with prevalence p=5%p = 5\% is, in practice, not reachable by logistic regression — and rarely reachable by any model on tabular clinical data of this size and signal-strength. The criterion is therefore guaranteed to fire: the simple model will always miss the target, by construction, and escalation will always be triggered. The discipline has been shaped, not applied. The defining property of earn complexity is that the baseline must have a real chance of being good enough; an unrealistically high target collapses the rule into a predetermined escalation, which is operationally identical to setup B (gradient boosting from the start), only dressed in disciplined language. A student who picks D has confused the syntax of the rule (a baseline + a number + an if-then) with the binding force of the rule (the number must be achievable; the not-escalate branch must have a real chance of being taken). Important precision: the failure mode in D is not "the target is too hard" per se — a hard target is fine if it is reachable. The failure is that the target is incompatible with the prevalence and the model class on this specific task: the historical AUPRC range published for 3030-day ICU readmission models on tabular clinical features of this kind is roughly 0.200.20–0.450.45, so a target of 0.800.80 is roughly twice the realistic ceiling on this task — and a 66-feature logistic regression is well below even that historical ceiling. A target set above the realistic frontier cannot fail in a way that informs escalation — it can only fail because it was unattainable, and that failure carries no information about whether the simpler model was good enough. Diagnostic for the corrector: in D, the if-then has only one real branch (escalate); in C, the if-then has two real branches (escalate or ship the baseline). A stop-criterion with only one real branch is not a stop-criterion — it is a plan disguised as a rule.

The single discriminator across A / B / C / D is whether the student reads earn complexity as a temporally-binding rule with a real-chance baseline: written before training (rules out A), starting from a simple model (rules out B), and tested against a realistic target on the actual prevalence (rules out D). Only C passes all three components together.

Rubric

N/A (MCQ — single correct option).
