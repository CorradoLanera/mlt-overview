Item 03 — RNN weight count and independence from sequence length

ID: IB-06-unstructured-data-03 Learning objective: Describe the recurrent operation a<t>=g(Waaa<t−1>+Waxx<t>+ba)a^{<t>} = g(W_{aa}\, a^{<t-1>} + W_{ax}\, x^{<t>} + b_a) and explain that the same matrices Waa,Wax,WyaW_{aa}, W_{ax}, W_{ya} are reused at every position tt, so the parameter count is independent of the sequence length TxT_x (Obj. 3). Category: Application Type: MCQ (scenarizzato) Difficulty: medium Chapter: 06-unstructured-data

Question

You are training a Recurrent Neural Network to flag early signs of cardiac arrhythmia from a multi-channel bedside monitor. At every time step t=1,…,Txt = 1, \ldots, T_x:

  • the input is a 44-dimensional reading: x<t>∈ℝ4x^{<t>} \in \mathbb{R}^{4} (heart rate, blood pressure, SpO2, temperature);
  • the hidden state is 2020-dimensional: a<t>∈ℝ20a^{<t>} \in \mathbb{R}^{20};
  • the output is a 33-dimensional probability vector: y<t>∈ℝ3y^{<t>} \in \mathbb{R}^{3} (no-event / pre-arrhythmia / arrhythmia).

The recurrent update is a<t>=g(Waaa<t−1>+Waxx<t>+ba)a^{<t>} = g(W_{aa}\, a^{<t-1>} + W_{ax}\, x^{<t>} + b_a) and the per-step output is y<t>=g′(Wyaa<t>+by)y^{<t>} = g'(W_{ya}\, a^{<t>} + b_y). Ignore biases for this item. A typical patient session yields Tx=2000T_x = 2\,000 time steps.

How many weights does the network have to learn, and does this count depend on TxT_x?

Options

  • A) 8080 weights, and the count depends on TxT_x (each time step has its own copy of the weights, so the total grows with the length of the session).
  • B) 8080 weights, and the count does NOT depend on TxT_x (the same weights are reused at every time step).
  • C) 540540 weights, and the count does NOT depend on TxT_x (the same matrices Waa,Wax,WyaW_{aa}, W_{ax}, W_{ya} are reused at every time step).
  • D) 540×2000=1080000540 \times 2\,000 = 1\,080\,000 weights, and the count depends on TxT_x (the network is fully unrolled over the 20002\,000 time steps and has independent weights at each step).

Expected answer

Correct: C. Decomposition of the weight count, matrix by matrix:

|Waa|=20×20=400,|Wax|=20×4=80,|Wya|=3×20=60.|W_{aa}| = 20 \times 20 = 400, \qquad |W_{ax}| = 20 \times 4 = 80, \qquad |W_{ya}| = 3 \times 20 = 60.

Total: 400+80+60=540400 + 80 + 60 = 540 weights. The count is independent of TxT_x because the chapter's central dispositive for sequences — weight sharing across time — says exactly that the same three matrices Waa,Wax,WyaW_{aa}, W_{ax}, W_{ya} are reused at every position tt. The recurrence unrolls in time, but the parameters do not. A patient session of Tx=2000T_x = 2\,000 and a session of Tx=10000T_x = 10\,000 are processed by the same 540540 weights.

Why the distractors are plausible but wrong:

The four options form a 2×22 \times 2 matrix of misconceptions along two axes: which matrices were counted (only WaxW_{ax}, 8080 weights — vs all three matrices, 540540 weights) × what TxT_x does to the count (multiplies it — vs does not).

  • A (80 weights, depends on TxT_x) combines both misconceptions: counted only WaxW_{ax} (input → hidden), forgot the recurrent matrix WaaW_{aa} (hidden → hidden) and the output matrix WyaW_{ya} (hidden → output), and assumed every time step has its own copy. A student who lands on A has not seen Obj. 3 at all; they are reading the RNN as if it were a sequence of unrelated input layers.
  • B (80 weights, does NOT depend on TxT_x) gets the scaling concept right but the count wrong: it correctly applies "the same matrices are reused at every tt" (Obj. 3's punchline) but counts only WaxW_{ax}, missing WaaW_{aa} and WyaW_{ya}. In a closed MCQ this misconception is scored as incorrect like the others — but the Nota docente below flags it as the response to look at in the asynchronous debrief: a student who picked B is much closer to mastery than a student who picked A or D, and that signal is worth re-using in the next class or the next item set.
  • D (1,080,000 weights, depends on TxT_x) is the unrolled-MLP fallacy: the student has correctly identified all three matrices (400+80+60=540400 + 80 + 60 = 540) and then multiplied by Tx=2000T_x = 2\,000, as if every time step were a separate copy of the network. This is exactly the wrong mental model the chapter is built to dispel. The student has done the matrix arithmetic correctly but has not internalised the purpose of the recurrent architecture — namely, that the recurrence reuses the same matrices, that is what makes it recurrent. The number 10800001\,080\,000 is also the number a naïve unrolling without weight sharing would yield — which is precisely the parameter explosion the RNN was designed to avoid.

The single discriminator is both axes simultaneously right: enumerate all three matrices (Waa,Wax,WyaW_{aa}, W_{ax}, W_{ya}) and recognise that they are shared across time. Only C does both.
