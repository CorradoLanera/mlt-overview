Item 03 — One step of gradient descent

ID: IB-05-deep-learning-03 Learning objective: Explain how a fully-connected network learns — weights as coordinates, loss as height, gradient descent W←W−η∇WL(W)W \leftarrow W - \eta \, \nabla_W L(W) as walking the model downhill (Obj. 3, the procedural half). Category: Application Type: MCQ (scenario) Difficulty: medium Chapter: 05-deep-learning

Question

A toy neural network has only two weights, w1w_1 and w2w_2. At the current weights Wnow=(w1,w2)=(3,1),W_{\text{now}} = (w_1,\ w_2) = (3,\ 1), the loss-landscape gradient has been computed (no need to redo the computation) and equals ∇WL(Wnow)=(2,−4).\nabla_W L(W_{\text{now}}) = (2,\ -4). The training procedure is gradient descent with learning rate η=0.5\eta = 0.5.

After one update step, the new weight vector WnextW_{\text{next}} is:

Options

  • A) Wnext=(2,3)W_{\text{next}} = (2,\ 3)
  • B) Wnext=(4,−1)W_{\text{next}} = (4,\ -1)
  • C) Wnext=(1,5)W_{\text{next}} = (1,\ 5)
  • D) Wnext=(5,−3)W_{\text{next}} = (5,\ -3)

Expected answer

Correct: A. Gradient descent updates the weights against the gradient, scaled by the learning rate: Wnext=Wnow−η∇WL(Wnow)=(3,1)−0.5⋅(2,−4)=(3,1)−(1,−2)=(2,3).W_{\text{next}} = W_{\text{now}} - \eta \, \nabla_W L(W_{\text{now}}) = (3,\ 1) - 0.5 \cdot (2,\ -4) = (3,\ 1) - (1,\ -2) = (2,\ 3).

That is, the update subtracts a small fraction of the gradient (a fraction set by η\eta) from the current weights — so the model moves downhill on the loss landscape, not too far in one step.

Each distractor isolates one specific misconception about the update rule:

  • B (Wnext=(4,−1)W_{\text{next}} = (4,\ -1)) — sign-flip error. The student has added η∇L\eta \nabla L instead of subtracting it: (3,1)+0.5⋅(2,−4)=(4,−1)(3,\ 1) + 0.5 \cdot (2,\ -4) = (4,\ -1). This is gradient ascent — it walks the model uphill on the loss landscape, increasing the error at every step. A student who picks B has reversed the central insight of Obj. 3 (descent goes opposite to the gradient).
  • C (Wnext=(1,5)W_{\text{next}} = (1,\ 5)) — forgot the learning rate. The student has subtracted the full gradient with no η\eta: (3,1)−(2,−4)=(1,5)(3,\ 1) - (2,\ -4) = (1,\ 5). The direction is correct (downhill), but the step size is wrong. In practice this is the most pedagogical mistake — it asks "what is η\eta for?", and the answer is exactly: to control how far you move along the descent direction at each step (a step too big can overshoot the minimum, oscillate, or diverge).
  • D (Wnext=(5,−3)W_{\text{next}} = (5,\ -3)) — both errors at once. The student has added the full gradient with no learning rate: (3,1)+(2,−4)=(5,−3)(3,\ 1) + (2,\ -4) = (5,\ -3). Direction wrong and step size wrong — both the sign and the η\eta have been lost. This is the option chosen by a student who is operating "by analogy" without having read the chapter's update rule at all.

The single discriminator is the update rule itself: subtract a fraction η\eta of the gradient. The sign decides whether you descend or ascend; the learning rate decides how far you step. Only A applies both correctly.
