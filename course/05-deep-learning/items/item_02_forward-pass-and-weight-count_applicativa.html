Item 02 — Forward pass and weight count of a small fully-connected network

ID: IB-05-deep-learning-02 Learning objective: Compose the forward pass of a small fully-connected network — given an architecture spec, write the per-layer equations a[l]=g[l](W[l]a[l−1])a^{[l]} = g^{[l]}(W^{[l]} a^{[l-1]}), identify the activation gg at each layer, count the total number of weights, and operate one forward pass numerically (Obj. 2). Category: Application Type: applicativa Difficulty: medium Chapter: 05-deep-learning

Question

Consider the following fully-connected neural network, with no bias terms:

  • Input layer: 33 features, written as a[0]=(x1,x2,x3)∈ℝ3a^{[0]} = (x_1, x_2, x_3) \in \mathbb{R}^3.
  • Hidden layer 1: 44 neurons, activation g[1]=ReLUg^{[1]} = \text{ReLU}, with ReLU(z)=max⁡(0,z)\text{ReLU}(z) = \max(0, z).
  • Hidden layer 2: 22 neurons, activation g[2]=ReLUg^{[2]} = \text{ReLU}.
  • Output layer: 11 neuron, activation g[3]=σg^{[3]} = \sigma (sigmoid), where σ(z)=1/(1+e−z)\sigma(z) = 1 / (1 + e^{-z}).

Answer the three sub-questions below in order.

Sub-question 1 — write the forward pass

Write the three forward-pass equations of this network in matrix form, a[l]=g[l](W[l]a[l−1])a^{[l]} = g^{[l]}(W^{[l]} a^{[l-1]}), naming the activation g[l]g^{[l]} at each layer. State the dimensions of each weight matrix W[l]W^{[l]} explicitly (number of rows × number of columns).

Sub-question 2 — count the weights

Compute the total number of weights that this network has to learn, showing the calculation decomposed by layer (one term per layer), not just the final number.

Sub-question 3 — operate one forward pass

Given the concrete input vector a[0]=(1,2,0)a^{[0]} = (1,\ 2,\ 0) and the concrete weight matrix W[1]=(10−1011−1102−20),W^{[1]} = \begin{pmatrix} 1 & 0 & -1 \\ 0 & 1 & 1 \\ -1 & 1 & 0 \\ 2 & -2 & 0 \end{pmatrix}, compute the first hidden layer's output vector a[1]=ReLU(W[1]a[0])a^{[1]} = \text{ReLU}(W^{[1]} a^{[0]}). Show the intermediate pre-activation vector z[1]=W[1]a[0]z^{[1]} = W^{[1]} a^{[0]} explicitly before applying ReLU.

Expected answer

Sub-question 1

The three forward-pass equations, with explicit matrix dimensions:

  • a[1]=ReLU(W[1]a[0])a^{[1]} = \text{ReLU}(W^{[1]} a^{[0]}), with W[1]∈ℝ4×3W^{[1]} \in \mathbb{R}^{4 \times 3}, so a[1]∈ℝ4a^{[1]} \in \mathbb{R}^4.
  • a[2]=ReLU(W[2]a[1])a^{[2]} = \text{ReLU}(W^{[2]} a^{[1]}), with W[2]∈ℝ2×4W^{[2]} \in \mathbb{R}^{2 \times 4}, so a[2]∈ℝ2a^{[2]} \in \mathbb{R}^2.
  • a[3]=σ(W[3]a[2])a^{[3]} = \sigma(W^{[3]} a^{[2]}), with W[3]∈ℝ1×2W^{[3]} \in \mathbb{R}^{1 \times 2}, so a[3]∈ℝa^{[3]} \in \mathbb{R} — this is the final scalar output ŷ\hat{y}.

A component-wise statement is also acceptable, e.g. aj[1]=ReLU(∑i=13Wji[1]xi)a^{[1]}_j = \text{ReLU}\!\left(\sum_{i=1}^{3} W^{[1]}_{ji} \, x_i\right) for j=1,…,4j = 1, \ldots, 4. ReLU at the two hidden layers, sigmoid at the output, must be named explicitly.

Sub-question 2

The decomposition by layer:

  • Layer 1 (3→43 \to 4): 3⋅4=123 \cdot 4 = 12 weights.
  • Layer 2 (4→24 \to 2): 4⋅2=84 \cdot 2 = 8 weights.
  • Layer 3 (2→12 \to 1): 2⋅1=22 \cdot 1 = 2 weights.

Total: 12+8+2=𝟐𝟐12 + 8 + 2 = \mathbf{22} weights.

(With no bias terms — as specified in the problem. If the problem had introduced biases, there would be 4+2+1=74 + 2 + 1 = 7 additional bias parameters, for a total of 2929.)

Sub-question 3

Compute the pre-activation vector z[1]=W[1]a[0]z^{[1]} = W^{[1]} a^{[0]} component by component:

  • z1[1]=1⋅1+0⋅2+(−1)⋅0=1z^{[1]}_1 = 1 \cdot 1 + 0 \cdot 2 + (-1) \cdot 0 = 1
  • z2[1]=0⋅1+1⋅2+1⋅0=2z^{[1]}_2 = 0 \cdot 1 + 1 \cdot 2 + 1 \cdot 0 = 2
  • z3[1]=(−1)⋅1+1⋅2+0⋅0=1z^{[1]}_3 = (-1) \cdot 1 + 1 \cdot 2 + 0 \cdot 0 = 1
  • z4[1]=2⋅1+(−2)⋅2+0⋅0=−2z^{[1]}_4 = 2 \cdot 1 + (-2) \cdot 2 + 0 \cdot 0 = -2

So z[1]=(1,2,1,−2)z^{[1]} = (1,\ 2,\ 1,\ -2).

Apply ReLU element-wise — ReLU(z)=max⁡(0,z)\text{ReLU}(z) = \max(0, z):

  • ReLU(1)=1\text{ReLU}(1) = 1
  • ReLU(2)=2\text{ReLU}(2) = 2
  • ReLU(1)=1\text{ReLU}(1) = 1
  • ReLU(−2)=0\text{ReLU}(-2) = 0 ← the negative pre-activation is killed by the non-linearity.

Final: a[1]=(1,2,1,0)a^{[1]} = (1,\ 2,\ 1,\ 0).

The teachable beat of this sub-question is the last component: the pre-activation is −2-2, the post-activation is 00. This is the non-linearity of g[1]g^{[1]} doing actual work — a student who writes a4[1]=−2a^{[1]}_4 = -2 has applied a linear function, not the ReLU specified in the architecture, and has implicitly turned the layer into a linear map (the very thing the chapter's requirement on gg rules out — see Obj. 3).
