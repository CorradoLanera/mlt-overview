Item 02 — Apply the kernel trick

ID: IB-03-algorithm-examples-02 Learning objective: Explain the kernel trick operationally — a non-linear feature map ϕ\phi can turn a non-linearly-separable dataset into a linearly-separable one without changing the linear classifier itself; only what the classifier sees changes (Obj. 2). Category: Application Type: applicativa (open-ended applicative) Difficulty: medium Chapter: 03-algorithm-examples

Question

Eight patients are described in a 2D feature space with features y1y_1 and y2y_2. Their classes are:

Patient y1y_1 y2y_2 Class
A 11 00 red
B −1-1 00 red
C 00 11 red
D 00 −1-1 red
E 33 00 blue
F −3-3 00 blue
G 00 33 blue
H 00 −3-3 blue

(Geometrically: the red patients lie on the unit circle y12+y22=1y_1^2 + y_2^2 = 1, the blue patients on the circle y12+y22=9y_1^2 + y_2^2 = 9 — concentric circles around the origin.)

A non-linear feature map is given:

ϕ(y1,y2)=(y12,y22)=(X1,X2).\phi(y_1, y_2) = (y_1^2,\ y_2^2) = (X_1, X_2).

Answer the four sub-questions:

  1. Argue briefly (1–2 sentences) why no straight line in the original (y1,y2)(y_1, y_2) plane can separate the red class from the blue class.
  2. Tabulate the transformed coordinates (X1,X2)=ϕ(y1,y2)(X_1, X_2) = \phi(y_1, y_2) for the 8 patients.
  3. State a linear decision rule in the new (X1,X2)(X_1, X_2) space — i.e. a rule of the form "red if aX1+bX2<caX_1 + bX_2 < c, blue otherwise" with specific values of aa, bb, cc — that separates the two classes perfectly on this sample. Verify your rule on one red point and one blue point.
  4. The "classifier" (a single straight cut in feature space) did not change between the original space and the transformed space. What did change, and why is that enough to make linear separation possible? (1–3 sentences.)

Expected answer

  1. Red and blue are concentric: every direction from the origin contains both a red point (at distance 11) and a blue point (at distance 33). Any straight line in the (y1,y2)(y_1, y_2) plane has both classes on the same side of it (the only way to enclose red while excluding blue would be a closed curve, not a straight line).

  2. Apply ϕ(y1,y2)=(y12,y22)\phi(y_1, y_2) = (y_1^2,\ y_2^2):

    Patient (y1,y2)(y_1, y_2) (X1,X2)=(y12,y22)(X_1, X_2) = (y_1^2, y_2^2) Class
    A (1,0)(1, 0) (1,0)(1, 0) red
    B (−1,0)(-1, 0) (1,0)(1, 0) red
    C (0,1)(0, 1) (0,1)(0, 1) red
    D (0,−1)(0, -1) (0,1)(0, 1) red
    E (3,0)(3, 0) (9,0)(9, 0) blue
    F (−3,0)(-3, 0) (9,0)(9, 0) blue
    G (0,3)(0, 3) (0,9)(0, 9) blue
    H (0,−3)(0, -3) (0,9)(0, 9) blue

    Note: all reds have X1+X2=1X_1 + X_2 = 1; all blues have X1+X2=9X_1 + X_2 = 9.

  3. Linear decision rule: "red if X1+X2<5X_1 + X_2 < 5, blue otherwise" (so a=b=1a = b = 1, c=5c = 5 — any cc strictly between 11 and 99 works). Verification:

    • Red A: X1+X2=1+0=1<5X_1 + X_2 = 1 + 0 = 1 < 5 → labelled red ✓
    • Blue E: X1+X2=9+0=9≥5X_1 + X_2 = 9 + 0 = 9 \ge 5 → labelled blue ✓ (The same check holds for all 8 patients.)

  4. What did change is the data — the same eight patients have been re-coordinatised by ϕ\phi, so the coordinates the classifier sees now expose the distance-from-the-origin information that was hidden in the original (y1,y2)(y_1, y_2) representation. The classifier is still a straight cut; it now operates on (X1,X2)=(y12,y22)(X_1, X_2) = (y_1^2, y_2^2) instead of (y1,y2)(y_1, y_2). The decision rule X1+X2<5X_1 + X_2 < 5 in ϕ\phi-space corresponds exactly to the boundary y12+y22<5y_1^2 + y_2^2 < 5 in original space — a circle — which is the boundary the data actually wanted. The kernel trick is this re-coordinatisation: change what the linear classifier sees, not the classifier.
